## 💡 TROUBLESHOOTING

### Build Fails?
```
1. Delete target folder
2. Run Step 3 again
3. Wait for completion
```

### Application won't start?
```
1. Make sure MySQL is running
2. Check no other app uses port 8080
3. Run Step 4 again
```

### Can't reach login page?
```
Double check URL:
✓ http://localhost:8080/neerjaPhysiotherpyClinic/login.html
✗ http://localhost:8080/login.html (wrong!)
```

### Login fails?
```
Check credentials:
Username: superadmin (lowercase)
Password: SuperAdmin@123 (exact case)
```

### Features not working?
```
1. Open DevTools: F12
2. Check Console tab for errors
3. Read ROUTING_FIXES_GUIDE.md
```
